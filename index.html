Things I've built

vxlan-tracer finds VXLAN MTU blackholes, the bug where small pings get through but large packets disappear and nothing is logged. It's a Go CLI that attaches four eBPF programs at once and tells you which of six things is going wrong.

LLMFirewall sits between an LLM agent and its MCP tools and stops prompt injection from turning into real tool calls. Across 4,200+ attack cases it cut the attack success rate from 100% to 48%, and to 0% for attacks that try to use write tools. It's on PyPI as llmfirewall.

A matching engine in C++20, the core of an exchange. It handles 20.7 million messages a second on one thread in a synthetic benchmark, with a median latency of 0.04 µs, and replays deterministically after a crash.

Edge Deployer is a desktop app for writing and deploying serverless functions to six providers (Cloudflare, AWS Lambda, Vercel, Netlify, Fly.io, Railway) without switching between their CLIs and dashboards.

There's also an offline reinforcement learning framework I wrote to test whether a policy trained on logs is safe to deploy. More detail on all of these is on the projects page.
